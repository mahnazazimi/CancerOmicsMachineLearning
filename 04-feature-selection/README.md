# Feature Selection and Biomarker Identification

This section contains hands-on machine learning practice focused on feature selection, feature reduction, and biomarker-oriented analysis using Breast cancer datasets.

## Breast Cancer Feature Reduction

The breast cancer analysis includes:

- Comparison of classification algorithms using cross-validation
- SVM-based classification
- Feature importance estimation
- Selection of the top predictive features
- Model training using a reduced feature set
- Comparison of model performance before and after feature reduction

## STAD Biomarker Identification

The gene-expression analysis includes:

- Differentially expressed gene filtering
- Tumor/normal classification
- Cross-validation for model comparison
- Random Forest classification
- Gene ranking based on feature importance
- Mapping gene identifiers to gene symbols
- Identification of candidate biomarker features
