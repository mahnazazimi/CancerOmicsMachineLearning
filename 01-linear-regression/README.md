# Cancer Omics Machine Learning

This repository documents hands-on machine learning for cancer omics data, including TCGA gene expression datasets, using R.

The project is developed progressively and focuses on applying statistical and machine learning approaches to cancer-related datasets.

## Topics

The repository will include practical implementations of:

- Data preprocessing and exploration
- Correlation analysis
- Regression
- Classification
- Feature selection
- Model training and prediction
- Train/test data splitting
- Model evaluation and validation
- Clustering
- Hyperparameter tuning

## Tools

- R
- Machine learning packages

## Status

Work in progress. The repository is being expanded progressively with additional machine learning methods and cancer omics analyses.
